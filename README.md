# MNIST-digit-recognition
I participated in in an online classification challenge on Kaggle and
compare performance of the following classifiers for the MNIST digit recognition task available to
Kaggle ( https://www.kaggle.com/competitions/digit-recognizer )

* A neural network with 10 neurons in a single output layer (choice of activation function and
loss function for training is left to you.
* A neural network with two hidden layers followed by a 10 neuron output layer (number of
neurons and activation function is left as a choice)
